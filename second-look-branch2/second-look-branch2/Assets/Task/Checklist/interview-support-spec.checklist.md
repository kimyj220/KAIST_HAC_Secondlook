# 면접 지원 기능명세와 TASK 반영

범위는 전문가 협업과 장문 면접 요약, 동일 지원자의 차수별 독립 기록과 일관성 검토, 비공개 내부 저장소, 웹 원문 및 Rokid 표시 경계다. 기존 실행 기능과 제품 클래스 구현은 별도 검증 대상이다.

- 담당: 기능명세·내부 저장소 문서 담당, TASK 계약 담당, 독립 통합 검토자.
- 완료 기준: 상세 명세와 관련 TASK의 책임·수용 기준이 일치하고, 검증하지 않은 기능의 상태가 분명하다.

## 조사

- [x] 기존 TASK 인덱스와 T004·T007·T011·T013·T014·T015·T017의 책임 확인
- [x] Windows USB/PnP·Bluetooth에서 이름으로 식별 가능한 Rokid/Android 인터페이스 및 로컬 ADB 확인
- [x] 공식 CXR-L 문서에서 Hi Rokid 연결과 Custom View 세션의 역할 확인

## 문서 반영

- [x] 기능명세와 내부 저장소 문서를 관련 TASK 및 순서표에 연결
- [x] 웹 원문·요약 근거·차수 경계·보관·HUD의 수용 기준과 업무 소유자 명시

## 검증

- [x] 문서 경로와 참조, 역할·차수·권한 용어를 교차 확인
- [ ] 상세 기능 구현과 웹/API 실행 확인
- [x] 사용자가 휴대전화 Hi Rokid에서 연결됨을 확인했다고 보고함
- [ ] Android CXR-L 인증 및 Custom View 세션을 실기기로 확인
- [ ] 실제 렌즈에서 승인된 한글 요약의 줄바꿈·잘림·갱신을 확인

Windows에서는 Rokid 또는 Android 이름으로 식별되는 장치를 확인하지 못했다. PATH 및 표준 Android SDK 위치에 ADB가 없어 휴대전화 디버깅 상태는 조회하지 못했다. Hi Rokid 앱의 연결 표시는 사용자가 확인했다. SDK 세션 및 렌즈 표시는 별개로 검증한다. [Rokid 공식 CXR-L SDK](https://developerdoc.rokid.com/sdk?lang=en)
