# 브랜치 2 관점 그래프 통합

브랜치 2의 면접관 대시보드와 기존 기록 기능을 보존하면서, 같은 사이트의 인접 탭에서 모의 면접 음성, 관점 그래프, 후속 면접 이관 흐름을 열 수 있게 한다.

오케스트레이터가 적용 범위와 실행 주소를 조정한다. 서버 담당이 경로와 저장소를 연결하고, UI 담당이 탭 이동과 그래프 화면을 통합한다. 독립 검증 담당이 기존 동작과 새 흐름을 임시 데이터베이스로 확인한다.

## 완료 기준

- [x] 브랜치 2의 기존 서버, 화면, 저장 방식과 별도 그래프 시연의 기능 범위를 확인했다.
- [x] 기존 대시보드와 새 그래프 화면을 같은 서버에서 열고 기존 및 신규 탭과 내장 화면 경로를 확인한다.
- [x] 기존 기록과 새 그래프 기록이 각각의 저장소에서 작동한다.
- [x] A와 B의 개인 기록은 확정 전 분리되며 두 사람 확정 뒤 공동 검토에서 원문 근거와 그래프 관계를 확인할 수 있다.
- [x] 모의 면접의 WAV 전체와 바이트 범위를 정상적으로 읽을 수 있다.
- [x] 승인한 질문을 C에게 이관하고 C의 후속 기록을 저장한 뒤 서버 재시작 후 다시 조회할 수 있다.
- [ ] 브라우저에서 기존 화면과 새 화면의 탭 이동을 확인한다. 검증용 브라우저의 로컬 주소 접근이 거부되어 실제 클릭은 확인하지 못했다.
- [ ] Gemini 실호출과 Android·Rokid 실기기 동작을 확인한다.

## 검증 기준

HTTP 응답과 임시 SQLite 데이터를 대조한다. WAV의 헤더, 범위 응답과 오디오 형식은 [RFC 9110 바이트 범위](https://www.rfc-editor.org/rfc/rfc9110.html#name-range-requests)와 [Python wave 문서](https://docs.python.org/3.11/library/wave.html)를 기준으로 확인한다. 자동 테스트 결과와 브라우저 실측 결과를 각각 기록한다.

## 독립 실행 결과

- 임시 포트에서 Python 3.11.0과 분리된 SQLite 파일로 기존 페이지와 API, 그래프 페이지의 HTML·CSS·JS가 응답하는지 확인했다. 기존 기록과 검토 값은 그래프 시연 시작과 서버 재시작 이후에도 유지되었다.
- 그래프 시연에서 A·B·C 접근 키 3개, 확정 전 관점 분리, 두 평가자 확정 조건, 원문과 동일한 e10·e14 근거 노드와 관계, C의 승인 질문·질문 사용·답변 저장을 확인했다. 서버를 재시작한 후 같은 C 접근 키로 후속 기록을 다시 읽었다.
- 원본 WAV의 SHA-256이 전사 자료와 일치했다. 16 kHz 단일 채널 16비트 PCM을 읽고 301.54초 길이, HEAD 응답, 일반·끝부분 바이트 범위 206 응답, 범위를 벗어난 416 응답을 확인했다.
- 임시 데이터만 사용했다. 실제 Gemini 호출과 Android·Rokid 실기기 검증은 수행하지 않았다.
- 별도 서버 도메인 클래스와 그 단위 테스트는 이번 시연 통합 범위 밖이다.
