# SECOND LOOK

같은 면접에서 두 평가자가 각각 포착한 순간과 해석을 원문에 연결해, 근거 중심의 공동 검토를 돕는 Android·Rokid Glasses Display 프로젝트입니다.

## 현재 상태

- 콘텐츠 기획·기술 명세와 19개 클래스별 TASK를 작성했습니다.
- 전체 구성은 사용자 검토·승인 대기이며, 명세 기반 구현은 아직 시작하지 않았습니다.
- `second-look/`에는 예시 발화를 사용하는 초기 로컬 프로토타입이 있습니다. 실제 Rokid 연동과 실기기 성능은 미검증입니다.
- AI는 평가자들의 근거 검토를 돕습니다. 자동 합격 판정이나 성격 추론은 하지 않습니다.

## 대상 환경

디스플레이형 웨이브가이드 Rokid Glasses와 Android 연동 앱을 기준으로 설계합니다. Hi Rokid/CXR-L, 실제 입력 이벤트, 화면 영역과 한국어 표시는 SDK·펌웨어·실기기로 확인해야 합니다. AI 처리는 현장 PC/서버와 별도 API를 사용하는 구성을 검토 중입니다.

## 공유 파일

기획 원본, 명세, TASK·검증 문서와 현재 프로토타입을 보관합니다. API 키, 로컬 데이터베이스, 녹음 runtime 데이터와 캐시는 버전 관리에서 제외합니다. 검증 문서의 미체크 항목은 실행 완료를 뜻하지 않습니다.
