# SECOND LOOK — 로컬 프로토타입

동의받은 모의 면접을 대상으로, 두 평가자의 독립적인 관점 기록과 사후 공동 검토를 실험하는 초기 버전입니다. 자동 채용 판단 기능은 없습니다.

## 실행

Python 3가 설치된 Windows에서 PowerShell을 열고 이 폴더로 이동한 뒤 실행합니다.

```powershell
python server.py
```

브라우저에서 <http://127.0.0.1:8765>를 엽니다. 종료는 서버 터미널에서 `Ctrl+C`를 누릅니다. 별도의 패키지 설치나 GPU는 필요하지 않습니다. 기록은 이 폴더의 `second-look.db`에 저장됩니다.

## 시연 흐름

1. 사전 작성된 예시 발화에서 A가 중요한 발화를 고르고 기준, 극성, 메모를 기록한 후 확정합니다.
2. B도 상대의 화면을 보지 않고 같은 방식으로 기록하고 확정합니다.
3. 함께 검토 화면에서 한 사람만 포착한 순간, 기준 차이, 해석 충돌을 확인하고 전체 발화와 대조합니다.
4. 공동 기록의 사실, 해석 차이, 질문, 변화와 다음 면접 질문을 기록합니다. 글래스 화면은 웹 시안으로 확인할 수 있습니다.

데모 데이터를 불러오려면 서버가 실행 중인 상태에서 PowerShell에서 아래 명령을 사용합니다. **기존 기록과 공동 기록이 모두 교체됩니다.**

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8765/api/demo -ContentType 'application/json' -Body '{}'
```

## 현재 범위와 한계

- 발화는 하드코딩된 예시이며, 녹음·전사·오디오 재생이나 실시간 북마크는 아직 없습니다.
- 분류는 같은 발화 ID, 기준, 극성에 따른 단순 규칙이며 의미 분석이나 AI가 아닙니다. 지지·반박 근거를 자동 검색하지 않습니다.
- 선택적으로 Gemini의 지지·반대 근거 추천을 요청할 수 있습니다. 발화 ID가 실제 존재하는지만 검사하며, 관계의 의미나 정확성을 보증하지 않습니다. 추천 수락·수정, 사전 점수, 관점 그래프 시각화, 질문의 해소 상태와 변경 이력은 아직 없습니다.
- HUD는 브라우저 시안이며 Rokid SDK나 하드웨어에 연결되지 않았습니다. 정확한 모델과 연결 환경을 확인한 뒤 구현합니다.
- 서버는 현재 컴퓨터의 localhost에서만 열립니다. 로그인이나 평가자별 접근 제어가 없어 독립 기록은 화면을 보지 않는 진행 방식에 의존합니다. 민감한 실제 면접 데이터에는 사용하지 마세요.
- Gemini 제안을 요청할 때만 해당 데이터가 외부에 전송됩니다. 시연용 데이터를 지우려면 서버를 종료한 후 `second-look.db` 파일을 삭제합니다.

## 선택 기능: Gemini로 근거 제안 받기

Rokid에서 Gemini를 선택해 사용할 수 있는 것과 별개로, 이 프로그램이 Gemini를 호출하려면 Google AI Studio의 Gemini API 키가 필요합니다. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 직접 확인하거나 생성하세요. 사용량과 무료 제공 여부는 계정과 모델에 따라 달라질 수 있습니다. 키는 채팅에 공유하지 마세요.

서버를 실행할 PowerShell 창에서만 다음을 입력합니다. 실제 키는 본인이 `여기에_키` 자리에 입력합니다.

```powershell
$env:GEMINI_API_KEY = '여기에_키'
python server.py
```

선택적으로 `$env:GEMINI_MODEL`로 사용 가능한 Gemini 모델을 지정할 수 있습니다. 기본값은 `gemini-3.5-flash-lite`입니다. 서버를 재시작해야 설정이 적용됩니다. 키는 서버 환경 변수에서만 읽고 브라우저로 보내지 않습니다.

두 평가자가 기록을 확정한 뒤 **함께 검토 → 지지·반대 근거 제안 받기**를 누르면 그때 발화와 두 평가자의 메모가 Google에 전송됩니다. 버튼을 누르지 않으면 전송되지 않습니다. 반드시 참여자가 외부 AI 서비스 전송에 동의한 모의 데이터만 사용하세요.

## Rokid Glasses 수동 HUD 시연

디스플레이가 있는 Rokid Glasses를 Android의 Hi Rokid 앱에 페어링한 다음, 공동 기록의 글래스용 질문을 휴대폰으로 옮겨 Hi Rokid의 텔레프롬프터에 직접 붙여 넣어 시연할 수 있습니다. 이는 수동 입력이며 앱에서 글래스로 자동 전송하는 기능이나 탭 북마크가 아닙니다. 기기와 한국어 표시를 실제로 검증해야 합니다.
